# Practicals

One folder per numerical practical or Methods session, named with a two-digit number and a short label, for example `01_methods`, `02_methods` and so on. The full title goes in the folder's README. Each folder should contain:

- `README.md`: aim, learning outcomes, data needed, how to run, and what to submit (if anything)
- Python scripts or notebooks
- any small helper files the practical needs

| Practical | Topic | Status |
| --- | --- | --- |
| [`01_methods`](01_methods/) | Getting started with Claude (desktop app, VS Code, terminal) and local models with Ollama | Materials available |
| [`02_methods`](02_methods/) | Computational techniques for paleoclimate research: LiPD data, PCA and EOF with corals and ENSO, power spectra | Materials available |
| [`03_methods`](03_methods/) | Introduction to Bayesian modelling: Bayes' theorem, conjugate priors and a hand-written MCMC sampler (glacier melt); group tasks on warming rate, abrupt-change timing and sea-ice forecasting | Materials available |
