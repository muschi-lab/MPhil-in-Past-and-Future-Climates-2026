# 01 Methods one: getting started with Claude

Set up the tools used in the Methods sessions: the Claude desktop app, Claude Code in VS Code or the terminal, and (optionally) free local models with Ollama.

## Guides

| File | Contents |
| --- | --- |
| [`Getting_Started_with_Claude.pdf`](Getting_Started_with_Claude.pdf) | Choosing between the desktop app, VS Code and the terminal; install steps; first session; troubleshooting |
| [`Ollama_Local_Models_Setup_Guide.pdf`](Ollama_Local_Models_Setup_Guide.pdf) | Running local models for free when you hit your usage limit: the Ollama chat window, Open WebUI in the browser, or Claude Code on a local model; model choice by RAM, troubleshooting |

Start with the first guide. Use the second if you run out of Claude usage, do not have a paid plan, or want to work offline.

## Data needed

None for this session. The Methods one data folder holds the HadCRUT5 dataset, [`data/01_methods/hadcrut5/`](../../data/01_methods/hadcrut5/), for use in the practicals.

## How to run

Follow the guides in order. Before the session, make sure `claude --version` (terminal route) or the Code tab (desktop route) works.
