# 01 Methods one: getting started with Claude

Set up the tools used in the Methods sessions: the Claude desktop app, Claude Code in VS Code or the terminal, and (optionally) Claude Code running on a local model with Ollama.

## Guides

| File | Contents |
| --- | --- |
| [`Getting_Started_with_Claude.pdf`](Getting_Started_with_Claude.pdf) | Choosing between the desktop app, VS Code and the terminal; install steps; first session; troubleshooting |
| [`Claude_Code_Ollama_Setup_Guide.pdf`](Claude_Code_Ollama_Setup_Guide.pdf) | Running Claude Code on a free local model through Ollama; setup, start-up command, troubleshooting |

Start with the first guide. Use the second only if you want to run Claude Code without an Anthropic account.

## Data needed

None for this session. The Methods one data folder holds the HadCRUT5 dataset, [`data/01/hadcrut5/`](../../data/01/hadcrut5/), for use in the practicals.

## How to run

Follow the guides in order. Before the session, make sure `claude --version` (terminal route) or the Code tab (desktop route) works.
