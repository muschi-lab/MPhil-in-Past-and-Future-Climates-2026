# HadCRUT5 annual global temperature anomaly

Annual global, Northern Hemisphere and Southern Hemisphere surface temperature anomalies, 1850–2025.

## File

`hadcrut5.csv` (186 data rows, one per year, plus a header)

| Column | Description | Units |
| --- | --- | --- |
| `year` | Calendar year | – |
| `global_anomaly` | Global mean surface temperature anomaly | °C |
| `nh_anomaly` | Northern Hemisphere mean anomaly | °C |
| `sh_anomaly` | Southern Hemisphere mean anomaly | °C |
| `global_lower_ci` | Lower bound of the global anomaly uncertainty range | °C |
| `global_upper_ci` | Upper bound of the global anomaly uncertainty range | °C |

Anomalies are relative to a reference period, which is not stated in the file. **Confirm the baseline before use in a practical.**

## Source and citation

Morice, C. P., et al. (2021). An updated assessment of near-surface temperature change from 1850: the HadCRUT5 data set. *Journal of Geophysical Research: Atmospheres*, 126, e2019JD032361. https://doi.org/10.1029/2019JD032361

Product page: https://www.metoffice.gov.uk/hadobs/hadcrut5/

## Provenance of this file

The CSV is an annual summary derived from the HadCRUT5 monthly gridded product. The derivation (averaging method, baseline, and which ensemble statistic is used for the uncertainty range) is **not documented in the file and must be added here by the instructors.**
