# Data

Datasets used in the numerical practicals. Each practical's README says which files it needs.

## Adding data (instructors)

- Keep the repository's total data under about 50 MB. GitHub rejects any single file over 100 MB.
- Put each dataset in its own subfolder, for example `data/<dataset-name>/`.
- Next to each dataset add a short `README.md` giving the source, citation, licence, variables and units, and the date it was downloaded.
- For larger files, store them elsewhere and add a download script to the practical instead.
